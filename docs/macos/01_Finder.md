# Finder

Настройки Finder, применяемые Bootstrap Toolkit.

## Применяемые настройки

| Настройка | Статус | Назначение |
|----------|:------:|------------|
| Показывать расширения файлов | ✅ | Отображение реальных расширений файлов. |
| Показывать скрытые файлы | ✅ | Доступ к служебным файлам (`.git`, `.env`, `.ssh`). |
| Показывать строку пути | ✅ | Отображение полного пути к текущей папке. |
| Показывать строку состояния | ✅ | Количество файлов и свободное место на диске. |
| Папки выше файлов | ✅ | Более удобная навигация по каталогам. |
| Предупреждение при смене расширения | ⚪ По умолчанию | Используется системное значение macOS. |
| Предупреждение при очистке Корзины | ⚪ По умолчанию | Используется системное значение macOS. |

## Проверка

Команда:

```bash
./bootstrap.sh --check
```

Проверяет все настройки Finder и сообщает, требуется ли их изменение.

## Что Toolkit не изменяет

- размер значков;
- расположение боковой панели;
- теги;
- настройки iCloud;
- параметры отображения отдельных папок.

## Совместимость

Проверено на:

- macOS Sequoia
- macOS Tahoe
