# Screenshots

Настройки скриншотов, применяемые Bootstrap Toolkit.

## Применяемые настройки

| Настройка | Статус | Назначение |
|----------|:------:|------------|
| Папка сохранения | ✅ | Все скриншоты сохраняются в `~/Screenshots`. |

## Проверка

Команда:

```bash
./bootstrap.sh --check
```

Проверяет настройки скриншотов.

## Совместимость

- macOS Sequoia
- macOS Tahoe
