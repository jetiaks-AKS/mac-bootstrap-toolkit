# Trackpad

Настройки трекпада, применяемые Bootstrap Toolkit.

## Применяемые настройки

| Настройка | Статус | Назначение |
|----------|:------:|------------|
| Tap to Click | ✅ | Нажатие касанием без физического клика. |
| Natural Scrolling | ✅ | Естественное направление прокрутки. |
| Tap Drag | ✅ | Перетаскивание объектов касанием. |

## Проверка

Команда:

```bash
./bootstrap.sh --check
```

Проверяет все настройки трекпада и сообщает, требуется ли их изменение.

## Совместимость

Проверено на:

- macOS Sequoia
- macOS Tahoe
