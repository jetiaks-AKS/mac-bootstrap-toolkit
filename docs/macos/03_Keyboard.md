# Keyboard

Настройки клавиатуры, применяемые Bootstrap Toolkit.

## Применяемые настройки

| Настройка | Статус | Назначение |
|----------|:------:|------------|
| Скорость повтора клавиш | ✅ | Более быстрый ввод текста. |
| Задержка перед повтором | ✅ | Быстрее начинается повтор символов при удержании клавиши. |

## Проверка

Команда:

```bash
./bootstrap.sh --check
```

Проверяет все настройки клавиатуры и сообщает, требуется ли их изменение.

## Совместимость

Проверено на:

- macOS Sequoia
- macOS Tahoe
