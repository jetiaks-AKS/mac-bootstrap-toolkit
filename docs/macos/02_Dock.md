# Dock

Настройки Dock, применяемые Bootstrap Toolkit.

## Применяемые настройки

| Настройка | Статус | Назначение |
|----------|:------:|------------|
| Эффект сворачивания Scale | ✅ | Более быстрый и лаконичный эффект анимации. |
| Сворачивать в иконку приложения | ✅ | Уменьшает количество значков в Dock. |
| Не показывать последние приложения | ✅ | Dock содержит только закреплённые приложения. |

## Проверка

Команда:

```bash
./bootstrap.sh --check
```

Проверяет все настройки Dock и сообщает, требуется ли их изменение.

## Что Toolkit не изменяет

- размер Dock;
- положение Dock;
- автоматическое скрытие;
- увеличение значков (Magnification);
- состав закреплённых приложений.

## Совместимость

Проверено на:

- macOS Sequoia
- macOS Tahoe
