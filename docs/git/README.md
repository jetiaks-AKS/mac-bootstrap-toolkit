## Используемая модель разработки

Проект использует простую схему, основанную на двух основных ветках:

```
main
```

Содержит только стабильные релизы.

```
develop
```

Используется для ежедневной разработки новых функций и исправлений.

Каждый стабильный релиз переносится из `develop` в `main` и помечается Git Tag.

---

## Принципы

- небольшие логически завершённые коммиты;
- понятные сообщения коммитов;
- стабильные версии только в `main`;
- вся разработка ведётся в `develop`;
- каждый релиз сопровождается обновлением документации;
- каждый стабильный релиз получает Git Tag.
