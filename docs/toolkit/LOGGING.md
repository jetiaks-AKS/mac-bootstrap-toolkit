# Система логирования Mac Bootstrap Toolkit

## Назначение

Все модули Mac Bootstrap Toolkit используют единую систему логирования.

Это обеспечивает одинаковый стиль вывода, упрощает сопровождение проекта и делает выполнение Toolkit понятным для пользователя.

---

# Основные принципы

Система логирования построена на следующих принципах:

- единый формат сообщений;
- единый стиль оформления;
- понятные уровни сообщений;
- отсутствие дублирования;
- минимальное количество лишнего вывода;
- совместимость с Quiet и Verbose режимами.

---

# Типы сообщений

## action()

Используется для отображения текущего выполняемого действия.

Пример:

```text
[....] Installing Homebrew...
```

---

## success()

Используется при успешном завершении операции.

Пример:

```text
[ OK ] Homebrew already installed
```

---

## warning()

Используется, когда выполнение может продолжаться, но обнаружена потенциальная проблема.

Пример:

```text
[WARN] Configuration file not found
```

---

## error()

Используется при критических ошибках, препятствующих дальнейшей работе.

Пример:

```text
[FAIL] Unable to install Homebrew
```

---

## info()

Используется для отображения дополнительной информации.

По умолчанию отображается только в Verbose Mode.

Пример:

```text
[INFO] Checking Internet connection...
```

---

# Правила использования

## action()

Используется только перед выполнением длительной или важной операции.

Не применяется для вывода диагностической информации.

---

## success()

Выводится после успешного завершения действия.

Сообщение должно быть кратким и описывать итог операции.

---

## warning()

Используется только в случаях, когда выполнение Toolkit может продолжаться.

Предупреждение не должно означать завершение работы с ошибкой.

---

## error()

Используется только при невозможности продолжить выполнение текущего действия.

После критической ошибки модуль самостоятельно принимает решение о завершении работы или возврате управления.

---

## info()

Используется исключительно для дополнительной информации.

Не должен содержать сообщений об ошибках или предупреждений.

Основное назначение — диагностика и режим Verbose.

---

# Стиль сообщений

Все сообщения должны быть:

- короткими;
- понятными;
- однозначными;
- написанными в одном стиле;
- без лишней технической информации.

Предпочтительно использовать простые английские формулировки.

Например:

```text
Homebrew already installed
```

вместо

```text
Homebrew installation has already been detected on the current system
```

---

# Quiet и Verbose

По умолчанию Toolkit работает в режиме Quiet.

В этом режиме отображаются только основные сообщения.

При использовании параметра:

```bash
./bootstrap.sh --verbose
```

дополнительно отображаются сообщения уровня `info()`.

Это позволяет получать расширенную диагностическую информацию без изменения поведения остальных модулей.

---

# Текущее состояние

На данный момент реализованы:

- action();
- success();
- warning();
- error();
- info();
- поддержка Quiet Mode;
- поддержка Verbose Mode;
- единый стиль логирования во всех основных модулях Toolkit.
