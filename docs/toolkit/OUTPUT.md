# Система вывода Mac Bootstrap Toolkit

## Назначение

Mac Bootstrap Toolkit использует единый стиль вывода информации в терминал.

Это позволяет сделать выполнение Toolkit понятным, последовательным и удобным для чтения независимо от количества выполняемых модулей.

---

# Основные принципы

Система вывода построена на следующих принципах:

- Quiet by Default;
- Verbose When Needed;
- единый стиль сообщений;
- единый формат секций;
- минимальное количество лишнего вывода;
- итоговая сводка выполнения.

---

# Режимы работы

## Quiet Mode

Режим по умолчанию.

Показывает только основную информацию:

- текущий модуль;
- выполняемое действие;
- результат выполнения;
- итоговую сводку.

Пример:

```text
==========================================
 Homebrew
==========================================

[ OK ] Homebrew already installed
```

---

## Verbose Mode

Включается параметром:

```bash
./bootstrap.sh --verbose
```

Дополнительно отображает:

- выполняемые проверки;
- найденные значения;
- диагностическую информацию;
- подробности выполнения модулей.

Пример:

```text
[INFO] Checking Internet connection...
[INFO] Internet connection available
```

---

# Структура вывода

Каждый модуль использует одинаковую структуру.

Пример:

```text
==========================================
 Workspace
==========================================

[....] Creating Workspace folders...
[ OK ] Workspace configuration loaded
```

Это обеспечивает единый стиль вывода во всём Toolkit.

---

# Итоговая сводка

После завершения Bootstrap отображается краткая статистика выполнения.

Пример:

```text
==========================================
 Summary
==========================================

[ OK ] Bootstrap completed successfully

------------------------------------------
Modules Checked : 11
Installed       : 0
Skipped         : 11
Warnings        : 0
Errors          : 0
------------------------------------------
Duration        : 17s
```

---

# Принципы оформления

При разработке новых модулей необходимо придерживаться следующих правил:

- использовать единый формат секций;
- выводить только необходимую информацию;
- не дублировать сообщения;
- соблюдать Quiet by Default;
- использовать Verbose только для дополнительной диагностики;
- завершать работу модуля итоговым сообщением.
