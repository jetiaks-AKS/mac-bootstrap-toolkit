# Модули Mac Bootstrap Toolkit

## Назначение

Toolkit построен по модульному принципу.

Каждый модуль отвечает только за одну область ответственности и может развиваться независимо от остальных компонентов системы.

---

# Структура модулей

```
modules/

├── core/
├── bootstrap/
├── discovery/
├── settings/
├── apps/
└── vscode/
```

---

# Core

Core содержит общие сервисы Toolkit.

Все остальные модули используют Core и не дублируют его функциональность.

## Common

Назначение:

Общие вспомогательные функции, используемые всеми компонентами Toolkit.

---

## Logger

Назначение:

Единая система вывода сообщений в терминал.

Используется всеми модулями проекта.

---

## Preflight

Назначение:

Проверка готовности системы перед выполнением Bootstrap.

Выполняет:

- проверку macOS;
- проверку подключения к Интернету;
- проверку Xcode Command Line Tools;
- получение прав администратора.

---

## Homebrew

Назначение:

Проверка и установка Homebrew.

---

## Git

Назначение:

Проверка и первоначальная настройка Git.

---

## SSH

Назначение:

Проверка готовности SSH для работы Toolkit.

Текущее состояние:

- проверка наличия SSH;
- проверка базовой конфигурации.


## Terminal

Назначение:

Проверка готовности терминального окружения.

Текущее состояние:

- проверка окружения Terminal;
- проверка необходимых компонентов.


## Config Engine

Назначение:

Единый API для чтения автоматически сгенерированных конфигурационных файлов Toolkit.

Основные функции:

- `config_sections()`
- `config_get()`

Config Engine используется Bootstrap-модулями вместо собственного разбора конфигурационных файлов.

---

# Bootstrap

Bootstrap отвечает за применение конфигурации на новом Mac.

## Workspace

Назначение:

Подготовка рабочего окружения.

Выполняет:

- создание структуры каталогов;
- восстановление Git-репозиториев;
- восстановление Workspace VS Code.

# Discovery

Discovery автоматически анализирует текущую систему пользователя.

Реализованы следующие модули:

- Workspace
- Git
- Homebrew
- VS Code
- App Store
- macOS

Результатом работы Discovery являются конфигурационные файлы, используемые Bootstrap.
