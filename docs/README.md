# Knowledge Base

Документация проекта **Mac Bootstrap Toolkit**.

В данном разделе содержится описание модулей, настроек и принципов работы Toolkit.

## Разделы

### macOS

Документация по настройкам macOS, применяемым Bootstrap Toolkit.

## Принципы

- Документируется только реализованный функционал.
- Один модуль = один документ.
- Документация всегда соответствует текущему коду проекта.
- При изменении модуля соответствующий документ должен быть обновлён.
