# Mac Blueprint

> Подсистема анализа рабочего пространства Mac Bootstrap Toolkit.

---

## Что такое Mac Blueprint?

Mac Blueprint — это новая подсистема Mac Bootstrap Toolkit.

Она автоматически анализирует рабочее пространство пользователя,
формирует конфигурацию Bootstrap Toolkit
и подготавливает рабочее пространство для последующего восстановления
на новом Mac.

Blueprint не является отдельным приложением.

Он является частью существующего Mac Bootstrap Toolkit.

---

## Главная идея

Mac Bootstrap Toolkit работает в двух направлениях.

Bootstrap:

Configuration

↓

System

Discovery:

System

↓

Configuration

Оба используют одинаковый формат конфигурационных файлов.

Discovery автоматически создаёт конфигурацию,
Bootstrap автоматически применяет её.

Таким образом Toolkit способен воспроизвести рабочее пространство пользователя
без ручного создания конфигурационных файлов.
