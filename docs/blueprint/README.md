# Mac Blueprint

> Следующее поколение Mac Bootstrap Toolkit.

---

## Что такое Mac Blueprint?

Mac Blueprint — это система, которая позволяет перенести не весь компьютер,
а только рабочее окружение пользователя.

В отличие от Time Machine, Blueprint не является резервной копией.

Он создаёт описание рабочего пространства пользователя и позволяет
воспроизвести его на любом новом Mac.

---

## Главная идея

Toolkit не пытается определить, что важно пользователю.

Вместо этого он:

1. Анализирует текущую систему.
2. Показывает найденные компоненты.
3. Позволяет пользователю самостоятельно выбрать необходимые.
4. Создаёт Blueprint.
5. Восстанавливает выбранное рабочее окружение на новом Mac.

Последнее решение всегда остаётся за пользователем.

---

## Основные принципы

- модульная архитектура;
- идемпотентность;
- Self-Healing;
- отсутствие "магии";
- никаких автоматических решений;
- пользователь полностью контролирует процесс.

```

```
