# Discovery Homebrew

> Спецификация первого модуля Discovery.

Статус: Draft

Версия: 0.1

---

# Назначение

Модуль Discovery Homebrew предназначен для автоматического анализа установленного программного обеспечения, установленного через Homebrew.

После завершения анализа модуль формирует конфигурационные файлы, полностью совместимые с Mac Bootstrap Toolkit.

Bootstrap не должен знать, были ли эти файлы созданы вручную или автоматически.

---

# Цель

Автоматически определить:

- Homebrew Packages;
- Homebrew Casks.

И сформировать соответствующие конфигурационные файлы.

---

# Что анализируется

## Packages

Все установленные Formulae.

Например:

- git
- jq
- yq
- bat
- eza
- ffmpeg

---

## Casks

Все установленные Casks.

Например:

- vlc
- rectangle
- keka
- stats

---

# Что НЕ анализируется

Discovery Homebrew сознательно не анализирует:

- зависимости Formulae;
- внутренние каталоги Homebrew;
- кэш Homebrew;
- историю установки;
- версии пакетов.

Discovery сохраняет только названия компонентов.

Версии определяются Bootstrap во время установки.

---

# Результат работы

После завершения анализа создаются файлы:

config/

brew-packages.conf

brew-casks.conf

---

# Формат файлов

Пример brew-packages.conf

```text
git
jq
yq
bat
eza
ffmpeg
```

Пример brew-casks.conf

```text
vlc
rectangle
keka
stats
```

---

# Принципы

Discovery ничего не устанавливает.

Discovery ничего не удаляет.

Discovery только анализирует систему и формирует конфигурацию.

---

# Совместимость

Полученные конфигурационные файлы должны использоваться существующим Bootstrap Toolkit без каких-либо изменений.

Discovery не создаёт собственный формат.

Он создаёт стандартные конфигурационные файлы Bootstrap Toolkit.

---

# Критерий успешного выполнения

Модуль считается завершённым, если:

✓ обнаружены все Formulae;

✓ обнаружены все Casks;

✓ автоматически сформированы конфигурационные файлы;

✓ Bootstrap способен использовать их без модификаций.
