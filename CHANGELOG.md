# Changelog

Все значимые изменения проекта **Mac Bootstrap Toolkit** документируются
в этом файле.

Формат основан на принципах **Keep a Changelog**.

---

## [2.0.0] - 09.08.2026

Первая стабильная версия Toolkit на основе архитектуры
**Discovery → Generated Configuration → Bootstrap**.

### Added

#### Discovery Engine

- Добавлен полноценный Discovery Engine.
- Добавлен автоматический анализ текущего рабочего окружения macOS.
- Добавлено обнаружение Homebrew Packages и Casks.
- Добавлено обнаружение приложений App Store.
- Добавлен экспорт Git Configuration.
- Добавлено обнаружение VS Code Extensions и Settings.
- Добавлено обнаружение структуры Workspace.
- Добавлено обнаружение Git Repositories и их метаданных.
- Добавлен Workspace Inventory.
- Добавлена автоматическая генерация конфигурации в `config/generated/`.

#### Workspace Bootstrap

- Добавлен Bootstrap Workspace.
- Добавлено восстановление структуры Workspace.
- Добавлено восстановление Git Repositories.
- Добавлена проверка Remote URL.
- Добавлена проверка текущей Git-ветки.
- Добавлено восстановление рабочей Git-ветки.
- Добавлена интеграция Workspace Bootstrap с Generated Configuration.

#### Configuration

- Добавлен единый Configuration Engine.
- Bootstrap переведён на использование Generated Configuration.
- Устранено дублирование пользовательских настроек между Discovery и Bootstrap.
- Зафиксирован принцип:

```text
Discovery
    ↓
Generated Configuration
    ↓
Bootstrap
````

#### CLI & Output

* Добавлен полноценный `--verbose` режим.
* Добавлен компактный режим вывода по умолчанию.
* Добавлен единый механизм детального вывода через `detail()`.
* Discovery показывает найденные объекты в Verbose Mode.
* Добавлена информация о создаваемых generated-конфигурациях.
* Summary адаптирован под режим выполнения Toolkit.

---

### Changed

#### Architecture

* Toolkit переведён от преимущественно ручной конфигурации к модели
  **Discovery → Generated Configuration → Bootstrap**.
* Generated Configuration стала основным источником данных для Bootstrap.
* Workspace выделен в отдельное направление Discovery и Bootstrap.
* Конфигурация macOS Settings переведена на Generated Configuration.
* Документация переработана с учётом целевой архитектуры проекта.

#### Output

* Унифицировано поведение Compact и Verbose Mode.
* Discovery-модули используют единый формат информационных сообщений.
* Убрано лишнее дублирование вывода.
* Summary теперь корректно отражает режим выполнения:
  Discovery, Bootstrap или Check.

---

### Fixed

* Исправлен формат App Store Discovery в Generated Configuration.
* Исправлено отображение App Store приложений в Verbose Mode.
* Исправлен Verbose Output для VS Code Discovery.
* Исправлен Verbose Output Workspace Discovery.
* Исправлен повторный импорт Dock Discovery.
* Исправлены мелкие проблемы Workspace Discovery.
* Исправлен общий текст Summary для разных режимов Toolkit.
* Исправлено соответствие Generated Configuration формату,
  используемому Bootstrap.

---

### Documentation

* Переработан основной README проекта.
* Обновлена архитектурная документация.
* Обновлён ROADMAP.
* Обновлён TODO.
* Документация разделена по назначению.
* Зафиксирована целевая модель развития Toolkit.
* Зафиксировано разделение между текущей реализацией и будущими
  архитектурными этапами.

## [1.1.0] - 04.08.2026

### Added

#### Core

* Добавлена модульная архитектура Toolkit.
* Добавлена единая система логирования (`INFO`, `OK`, `WARN`, `ERROR`).
* Добавлен режим проверки (`--check`).
* Добавлен режим Bootstrap (`--bootstrap`).
* Добавлена команда `--help`.
* Добавлена команда `--version`.
* Добавлен стартовый экран Toolkit с отображением версии и режима работы.

#### Homebrew

* Автоматическая установка Homebrew.
* Проверка установленного Homebrew.
* Автоматическая установка CLI-пакетов из конфигурационного файла.
* Автоматическая установка GUI-приложений (Casks) из конфигурационного файла.
* Поддержка `brew install --cask --adopt` для существующих приложений.
* Добавлено автоматическое восстановление Homebrew Casks.
* Добавлена проверка результата после установки (Verify After Apply).

#### Git

* Проверка установки Git.
* Автоматическая настройка Git.

#### SSH

* Проверка SSH-конфигурации.

#### Terminal

* Проверка готовности терминала.

#### App Store

* Добавлена поддержка Mac App Store через `mas`.
* Автоматическая установка приложений из `config/appstore.conf`.
* Проверка уже установленных приложений перед установкой.

#### VS Code

* Проверка доступности VS Code CLI (`code`).
* Автоматическая установка расширений из `config/vscode-extensions.conf`.
* Проверка уже установленных расширений.
* Автоматическая установка только отсутствующих расширений.
* Автоматическое применение `settings.json`.
* Резервное копирование существующих настроек VS Code.
* Проверка актуальности настроек перед их применением.

#### macOS

* Добавлена модульная настройка Finder.
* Добавлена модульная настройка Dock.
* Добавлена модульная настройка Keyboard.
* Добавлена модульная настройка Trackpad.
* Добавлена модульная настройка Screenshots.
* Добавлена идемпотентная проверка текущих настроек перед применением.

#### Configuration

* Добавлены конфигурационные файлы:

  * `brew-packages.conf`
  * `brew-casks.conf`
  * `appstore.conf`
  * `vscode-extensions.conf`
* Добавлен каталог `settings/`.
* Добавлены шаблоны настроек VS Code.

#### Project

* Добавлена единая структура проекта.
* Добавлена поддержка отдельных модулей.
* Добавлено разделение на:

  * `modules`
  * `config`
  * `settings`
* Добавлен файл `TODO.md`.
* Добавлен модуль `macos.sh`.
* Добавлены скрипты экспорта настроек macOS.
* Добавлены скрипты анализа настроек macOS.

#### Output

* Добавлен режим `--verbose`.
* Добавлен компактный режим вывода по умолчанию.
* Добавлена поддержка детального вывода (`detail()`).
* Добавлен Quiet Mode для операций установки.
* Добавлен итоговый Summary с расширенной статистикой.
