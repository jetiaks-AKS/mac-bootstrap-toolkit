# Changelog

Все значимые изменения проекта **Mac Bootstrap Toolkit** будут документироваться в этом файле.

Формат основан на принципах **Keep a Changelog**.

---

## [Unreleased]

### Added

#### Core

- Добавлена модульная архитектура Toolkit.
- Добавлена единая система логирования (`INFO`, `OK`, `WARN`, `ERROR`).
- Добавлен режим проверки (`--check`).
- Добавлен режим Bootstrap (`--bootstrap`). 
- Добавлена команда `--help`.
- Добавлена команда `--version`.
- Добавлен стартовый экран Toolkit с отображением версии и режима работы.

#### Homebrew

- Автоматическая установка Homebrew.
- Проверка установленного Homebrew.
- Автоматическая установка CLI-пакетов из конфигурационного файла.
- Автоматическая установка GUI-приложений (Casks) из конфигурационного файла.
- Поддержка `brew install --cask --adopt` для существующих приложений.

#### Git

- Проверка установки Git.
- Автоматическая настройка Git.

#### SSH

- Проверка SSH-конфигурации.

#### Terminal

- Проверка готовности терминала.

#### App Store

- Добавлена поддержка Mac App Store через `mas`.
- Автоматическая установка приложений из `config/appstore.conf`.
- Проверка уже установленных приложений перед установкой.

#### VS Code

- Проверка доступности VS Code CLI (`code`).
- Автоматическая установка расширений из `config/vscode-extensions.conf`.
- Проверка уже установленных расширений.
- Автоматическая установка только отсутствующих расширений.
- Добавлено автоматическое применение `settings.json`.
- Добавлено резервное копирование существующих настроек VS Code.
- Добавлена проверка актуальности настроек перед их применением.

#### macOS

- Добавлена модульная настройка Finder.
- Добавлена модульная настройка Dock.
- Добавлена модульная настройка Keyboard.
- Добавлена модульная настройка Trackpad.
- Добавлена модульная настройка Screenshots.
- Добавлена проверка текущих настроек macOS перед применением.

#### Configuration

- Добавлены конфигурационные файлы:
  - `brew-packages.conf`
  - `brew-casks.conf`
  - `appstore.conf`
  - `vscode-extensions.conf`
  - Добавлен каталог `settings/`.
  - Добавлены шаблоны настроек VS Code.

#### Project

- Добавлена единая структура проекта.
- Добавлена поддержка отдельных модулей.
- Добавлено разделение на:
  - `modules`
  - `config`
  - `settings`
- Добавлен файл `TODO.md`.
- Добавлен модуль `macos.sh`.
- Добавлены скрипты экспорта настроек macOS.
- Добавлены скрипты анализа настроек macOS.
- Обновлена проектная документация.
