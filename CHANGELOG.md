# Changelog

Все значимые изменения проекта **Mac Bootstrap Toolkit** будут документироваться в этом файле.

Формат основан на принципах **Keep a Changelog**.

---

## [1.1.0] - 04.08.2026

### Added

#### Core

- Добавлена модульная архитектура Toolkit.
- Добавлена единая система логирования (`INFO`, `OK`, `WARN`, `ERROR`).
- Добавлен режим проверки (`--check`).
- Добавлен режим Bootstrap (`--bootstrap`).
- Добавлена команда `--help`.
- Добавлена команда `--version`.
- Добавлен стартовый экран Toolkit с отображением версии и режима работы.

#### Homebrew

- Автоматическая установка Homebrew.
- Проверка установленного Homebrew.
- Автоматическая установка CLI-пакетов из конфигурационного файла.
- Автоматическая установка GUI-приложений (Casks) из конфигурационного файла.
- Поддержка `brew install --cask --adopt` для существующих приложений.
- Добавлено автоматическое восстановление (Self-Healing) Homebrew Casks.
- Добавлена проверка результата после установки (Verify After Apply).

#### Git

- Проверка установки Git.
- Автоматическая настройка Git.

#### SSH

- Проверка SSH-конфигурации.

#### Terminal

- Проверка готовности терминала.

#### App Store

- Добавлена поддержка Mac App Store через `mas`.
- Автоматическая установка приложений из `config/appstore.conf`.
- Проверка уже установленных приложений перед установкой.

#### VS Code

- Проверка доступности VS Code CLI (`code`).
- Автоматическая установка расширений из `config/vscode-extensions.conf`.
- Проверка уже установленных расширений.
- Автоматическая установка только отсутствующих расширений.
- Автоматическое применение `settings.json`.
- Резервное копирование существующих настроек VS Code.
- Проверка актуальности настроек перед их применением.

#### macOS

- Добавлена модульная настройка Finder.
- Добавлена модульная настройка Dock.
- Добавлена модульная настройка Keyboard.
- Добавлена модульная настройка Trackpad.
- Добавлена модульная настройка Screenshots.
- Добавлена идемпотентная проверка текущих настроек перед применением.

#### Configuration

- Добавлены конфигурационные файлы:
  - `brew-packages.conf`
  - `brew-casks.conf`
  - `appstore.conf`
  - `vscode-extensions.conf`
- Добавлен каталог `settings/`.
- Добавлены шаблоны настроек VS Code.

#### Project

- Добавлена единая структура проекта.
- Добавлена поддержка отдельных модулей.
- Добавлено разделение на:
  - `modules`
  - `config`
  - `settings`
- Добавлен файл `TODO.md`.
- Добавлен модуль `macos.sh`.
- Добавлены скрипты экспорта настроек macOS.
- Добавлены скрипты анализа настроек macOS.

#### Output

- Добавлен режим `--verbose`.
- Добавлен компактный режим вывода по умолчанию.
- Добавлена поддержка детального вывода (`detail()`).
- Добавлен Quiet Mode для операций установки.
- Добавлен итоговый Summary с расширенной статистикой.

## [1.0.0] - 03.08.2026

Первая стабильная версия Mac Bootstrap Toolkit.

## [1.2.0-dev]

### Added

#### Discovery Engine

- Добавлен полноценный Discovery Engine.
- Добавлена поддержка автоматического анализа Workspace.
- Добавлен экспорт структуры пользовательских каталогов.
- Добавлен экспорт Git-репозиториев.
- Добавлен экспорт VS Code Projects.
- Добавлен экспорт VS Code Workspaces.
- Добавлена генерация Inventory Workspace.
- Добавлена автоматическая генерация конфигураций в `config/generated/`.

#### Bootstrap

- Начата интеграция Bootstrap Engine с Discovery Engine.
- Добавлен модуль Bootstrap Workspace.
- Добавлено автоматическое восстановление структуры Workspace.
- Добавлено автоматическое восстановление отсутствующих Git-репозиториев на основе Discovery Configuration.
- Добавлена проверка существования Git-репозитория.
- Добавлена проверка Remote URL репозитория.
- Добавлена проверка текущей Git-ветки.
- Добавлено автоматическое восстановление рабочей Git-ветки при несовпадении с результатами Discovery.
- Добавлена проверка наличия незакоммиченных изменений перед автоматическим переключением Git-ветки.
- Bootstrap начал использовать автоматически сгенерированные конфигурации Discovery.
- Добавлен новый сервис Core — Config Engine.
- Реализованы функции `config_sections()` и `config_get()`.

#### Workspace

- Добавлен анализ структуры Workspace.
- Добавлено определение пользовательских, системных и рабочих каталогов.
- Добавлена поддержка анализа Git-репозиториев.
- Добавлен экспорт информации о состоянии Git-репозиториев.
- Добавлен анализ конфигурации VS Code для каждого репозитория.

#### Documentation

- Полностью переработан ROADMAP.
- Обновлён README проекта.
- Обновлён QUICKSTART.
- Обновлена документация COMMANDS.
- Переработан TODO как технический Backlog проекта.
- Добавлены README для новых разделов проекта.

---

### Changed

- Toolkit постепенно переходит от ручных конфигурационных файлов к автоматически генерируемым конфигурациям Discovery.
- Bootstrap Engine начал использовать результаты Discovery вместо ручной конфигурации.
- Переработана архитектура Workspace.
- Улучшена структура модулей Bootstrap.
- Унифицирована структура документации проекта.
- Уточнена концепция развития Toolkit.
- Экспериментальный Parser Engine заменён на новый Config Engine.
- Bootstrap Workspace переведён на использование Config Engine для чтения автоматически сгенерированных конфигурационных файлов.
- Bootstrap Workspace теперь способен автоматически восстанавливать Git-репозитории вместо выполнения только проверки конфигурации.
- Bootstrap Workspace теперь автоматически восстанавливает рабочую Git-ветку после проверки конфигурации репозитория.
- Автоматическое восстановление Git-репозиториев интегрировано с системой статистики Toolkit (`MODULE_CHANGED`).

- Исправлены мелкие ошибки Discovery Engine.

- Исправлена обработка автоматического переключения Git-веток.
