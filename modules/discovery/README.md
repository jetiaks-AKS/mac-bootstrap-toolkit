# Discovery Engine

## Назначение

Discovery Engine анализирует текущий Mac и формирует описание системы.

Discovery никогда ничего не изменяет.

Его единственная задача — собрать информацию и сохранить её в каталог `config/generated`.

---

## Что умеет Discovery

- Анализ Homebrew
- Анализ App Store
- Анализ Git
- Анализ VS Code
- Анализ настроек macOS
- Анализ рабочего пространства (Workspace)

---

## Принцип работы

Каждый модуль отвечает только за свою область.

Например:

- Homebrew экспортирует только Homebrew.
- Git экспортирует только Git.
- Workspace экспортирует только описание рабочего пространства.

После завершения анализа все данные используются модулем Blueprint для построения плана восстановления.

---

## Важно

Discovery не изменяет систему.

Он только читает текущую конфигурацию и формирует её описание.
