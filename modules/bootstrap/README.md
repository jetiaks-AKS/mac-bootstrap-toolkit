# Bootstrap Modules

## Назначение

Данный раздел содержит модули, отвечающие за восстановление рабочего окружения на новом Mac.

Bootstrap использует конфигурационные файлы, сформированные модулем Discovery, и применяет их к системе.

---

## Основная задача

Воссоздать рабочую среду пользователя автоматически.

---

## Принцип работы

Discovery
↓
config/generated/
↓
Bootstrap
↓
Новый Mac

---

## Состав

### Workspace

Восстановление структуры рабочего пространства:

- создание рабочих папок;
- клонирование Git-репозиториев;
- восстановление VS Code Workspace;
- восстановление структуры проектов.
