# Bootstrap Workspace

## Назначение

Модуль отвечает за восстановление рабочего пространства пользователя.

Источником данных являются конфигурационные файлы, сформированные Discovery.

---

## Используемые конфигурации

- folders.conf
- repositories.conf
- vscode-workspaces.conf
- vscode-projects.conf

---

## Основные задачи

### Folders

Создание структуры каталогов пользователя.

### Repositories

Клонирование Git-репозиториев.

Если репозиторий не удаётся клонировать или проверить, его remote не
совпадает с конфигурацией либо ветку нельзя восстановить из-за
незакоммиченных изменений, Bootstrap продолжает обработку остальных
репозиториев и завершает Workspace с предупреждением. Существующие
данные и Git remote при этом не изменяются.

### VS Code

Восстановление рабочих пространств и проектов VS Code.

---

## Принцип работы

Discovery
↓
config/generated/workspace/

Bootstrap Workspace
↓
Готовое рабочее окружение
