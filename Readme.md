# Mac Bootstrap Toolkit

Автоматическая подготовка нового Mac к работе за несколько минут.

Текущая версия: **1.0.0 (Stable)**.

---

## Возможности

- установка необходимого ПО;
- настройка macOS;
- настройка рабочего окружения;
- автоматизация повторяющихся действий;
- сокращение времени подготовки нового Mac.

---

## Принципы

- модульная архитектура;
- безопасный повторный запуск;
- минимум ручных действий;
- понятный код;
- подробное логирование;
- документация для каждого модуля.
